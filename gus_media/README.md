# Médias de Gus — Harmonie

Les dix paires de médias WebP animé avec transparence et audio M4A d’origine sont chargées par `integration.js` dans `tablette.html`.

- Début : `05_Presentation`
- Prout : `01_Prout`
- Toucher Gus : `06_Rires`
- Bonne réponse : choix aléatoire entre `02_Bravo`, `03_Danse`, `06_Rires` et `10_Bravo_bis`
- Réponse incorrecte : `04_Oups`
- Fin de mission : `08_Au_revoir`
- Les dix clips sont disponibles dans la barre de test sous Gus.

Les clips de présentation `05_Presentation` et `09_Presentation_bis` ont une piste audio AAC présente, mais silencieuse dans les sources MP4 fournies. Les huit autres pistes contiennent du son. Le clip `08_Au_revoir` garde un petit artefact de détourage sur la mèche, déjà signalé dans le paquet source.

Ne pas fusionner cette branche dans `main` sans validation.
